Review Room · Media architecture

One media hub, from upload to delivery.

Originals stay in RustFS. Convex keeps the catalog and review state; background jobs prepare video previews. Publishing is a separate, deliberate action.

Two paths, one catalog. Browser uploads and scoped automation APIs both create reviewable assets and versions. The illustrated worker path is for video; still images do not require video-derivative jobs.

Sources remain intact. Trailer Feed receives version references and authorized media access. Sync, refresh and unsync have explicit state; uploading alone never makes an asset public.
